01 · Anatomy

Компонентная структура

Explore — это профиль существующего Left Rail, а не отдельный sidebar. Общий shell, Spaces tree, pinned-состояния и navigation selection не дублируются.

Rail shell

Фиксирует ширину, фон, высоту, padding и единую scroll-area.

.spaces-sidebar

Shared content

Primary navigation, Pinned и Spaces одинаковы в двух профилях.

.spaces-sidebar-primary

Explore extension

Показывается только при активном profile value explore.

[data-explore-section]
Implementation boundary

Не создавайте второй DOM-tree для Explore. Переключатель профиля должен менять только modifier class, visibility секции и представление пункта Assets/More.

05 · Interaction

Поведение и storage-контракт

Preferences относятся к lab UI. В production их нужно привязать к согласованному preferences layer, если требуется cross-device sync.

Profile switch

  • При explore показать секцию Explore.
  • Заменить label/icon More на Assets.
  • Закрыть открытый More popover.
  • Обновить aria-pressed profile controls.
  • Не перезагружать страницу.

Collapse

  • Клик по chevron переключает только Explore content.
  • Обновить aria-expanded и action label.
  • Анимация: max-height 180ms, opacity 120ms.
  • В collapsed state контент не принимает pointer events.
  • При reduced motion переход выполняется без анимации.

Failure behavior

06 · Accessibility

Семантика и клавиатура

Минимальный контракт для production-компонента.

Required semantics

  • Общий контейнер — nav с доступным именем.
  • Destination — нативная ссылка, если меняется URL; иначе button.
  • Активный route получает aria-current="page".
  • Collapse control связан с content через aria-controls.
  • Декоративные иконки имеют пустой alt и aria-hidden.

Keyboard behavior

  • Tab order следует визуальному порядку сверху вниз.
  • Enter/Space активируют collapse button.
  • Focus indicator не полагается только на selected background.
  • Скрытый collapsed content исключён из keyboard flow.
  • При profile switch фокус остаётся на выбранном control.

07 · Developer handoff

Implementation contract

Ниже — минимальная логика переключения. Код иллюстрирует контракт, а не требует сохранения текущего inline-script в production. 

type SidebarProfile = "sidebar" | "explore";
type LeftRailDensity = "default" | "comfortable";

interface LeftRailPreferences {
  profile: SidebarProfile;          // default: "explore"
  exploreCollapsed: boolean;        // default: false
  density: LeftRailDensity;         // default: "default"
}

function applyExploreProfile(root, preferences) {
  const isExplore = preferences.profile === "explore";

  root.classList.toggle("is-explore-profile", isExplore);
  root.classList.toggle(
    "is-comfortable-density",
    preferences.density === "comfortable"
  );

  exploreSection.hidden = !isExplore;
  exploreSection.classList.toggle(
    "is-collapsed",
    preferences.exploreCollapsed
  );

  assetsLabel.textContent = isExplore ? "Assets" : "More";
  collapseButton.ariaExpanded =
    String(!preferences.exploreCollapsed);
}

Current source files

  • public/spaces-static/get-started_spaces.htmlMarkup, state application, preferences controls.
  • public/spaces-static/assets/css/spaces-overrides.cssRail layout, tokens, density and animation.
  • public/spaces-static/assets/js/spaces-sidebar-navigation.jsActive selection and Space/collection navigation.
  • public/icons/*.svgExplore and Assets icons.

Production integration notes

  • Вынести preferences из inline script в UI preferences adapter.
  • Подключить реальные routes для восьми Explore destinations.
  • Сохранить единый navigation selection state.
  • Не привязывать UI напрямую к analytics vendor.
  • Добавить typed event только после согласования product analytics.

SC-42Account без SpacesОбязательный edge case

Предусловия

SC-43Space удалён или доступ отозванОбязательный edge case

Предусловия

Сохранённый active/pinned Space больше недоступен.

Production result

Удалить stale item из rail/preferences, выбрать первый доступный Space или Home и показать понятное уведомление.

Security

Не показывать cached название, preview или files после revoke.

History

Старый route должен завершиться 403/404 state без navigation loop.

SC-44Storage недоступен или повреждёнРеализовано

Примеры

Ожидаемый результат

Rail работает с безопасными defaults; navigation не блокируется.

Recovery

Некорректные массивы pinned/expanded трактуются как пустые.

Telemetry

Production может записать техническую ошибку без PII и без прямой зависимости UI от vendor.

SC-45Навигация только с клавиатурыОбязательный edge case

Шаги

Использовать Tab, Shift+Tab, Enter, Space и Escape без pointer.

Production result

Все actions доступны в визуальном порядке; focus видим; collapse и popovers управляются с клавиатуры.

Collapsed content

Скрытые items не получают focus.

Drag alternative

Нужен keyboard-способ pin/reorder или доступная альтернатива drag-and-drop.

SC-46Маленькая высота и переполнение railРеализовано

Предусловия

Низкий viewport, раскрыто несколько деревьев и Explore.

Ожидаемый результат

Один vertical scroll owner показывает весь rail; scrollbar gutter стабилен.

Hover

Thumb: G20 при hover rail, G40 при hover scrollbar.

Не должно происходить

Нет overlap, horizontal scroll, обрезания chevron или двойного вложенного скролла.

SC-47Узкий viewport, touch и reduced motionОбязательный edge case

Текущее поведение

Rail сохраняет фиксированную ширину 256px; весь prototype имеет desktop fixed-width baseline.

Production decision

Явно выбрать: overlay drawer, fixed desktop canvas или отдельная mobile navigation.

Touch

Controls должны иметь достаточный hit area; drag не должен конфликтовать с vertical scroll.

Motion

При prefers-reduced-motion collapse/reorder transitions отключаются.

09 · Definition of done

Acceptance checklist

Критерии, по которым разработчик и дизайнер принимают Explore rail.

Visual

  • Rail ровно 256px; контент не сжимает его.
  • Base rows 36px; comfortable rows 40px.
  • Иконки 20×20px; horizontal gap 12px.
  • Hover и selected визуально различимы.
  • Scrollbar не вызывает horizontal layout shift.
  • Explore section следует сразу после Spaces.

Functional

  • Explore является default profile на чистом storage.
  • Profile, density и collapse переживают reload.
  • Storage failure не ломает rail.
  • Collapse state синхронизирован с ARIA.
  • More popover недоступен в Explore profile.
  • Активный route единственный и получает aria-current.
Перед Production

Отдельно проверить реальные URL Explore, analytics events, permissions для account-specific destinations и поведение rail на минимальной поддерживаемой высоте viewport. Эти части prototype пока не подтверждает.
